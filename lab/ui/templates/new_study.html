New study

The task YAML defines data paths, metrics, model registry, and prompt slots. To add a new task, drop config/tasks/<name>.yaml and an adapter class in lab/tasks/.

If selected, the new study's memory is seeded from the predecessor so the agent can see what has already been tried.

Prompt versions

Pick a specific version per prompt task for A/B testing, or leave on active to use whatever version is currently marked active in config/prompts/_registry.yaml. Results are attributed to the chosen version in the prompt score aggregation.
