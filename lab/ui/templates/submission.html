How to submit on Kaggle

  1. Open Kaggle → Datasets → New Dataset.
  2. Upload weights.pt (downloaded above). Give it a slug like birdclef-2026-weights-{{ study.id }} and make it private.
  3. On the BirdCLEF+ 2026 competition page, open a new notebook and upload submission.ipynb.
  4. In the notebook's right sidebar → Add Data → search for the dataset you just created and attach it.
  5. Run all cells. The notebook auto-finds weights.pt via Path('/kaggle/input').rglob('*.pt'); override with the env var AGENT_WEIGHTS_PATH if you renamed it.
  6. Click Submit on the notebook output → Kaggle scores the resulting submission.csv.
